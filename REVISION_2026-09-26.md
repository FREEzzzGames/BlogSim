# Tube Empire — ревизия Develop

## Что исправлено
- Единый источник денег: `tube_empire_state_v1`.
- Старый `zeitarbeitMoney` используется только для миграции/совместимости.
- Добавлен единый пассивный Income Engine: доход от холдингов + доход канала по подписчикам.
- Офлайн/пассивный доход рассчитывается при возврате в игру; один расчёт ограничен 24 часами.
- Восстановлены API корпораций: список, покупка, владение, доход/сек.
- `Economy`/`GameEconomy` получил совместимые методы, которых ожидал `game-logic.js`.
- Убран битый путь `economy.js` из главного меню.
- Восстановлен рабочий перевод спонсору прямо в меню вместо отсутствующего `transfer.html`.
- Исправлены ссылки на `tube-theme.css`.
- Аватар синхронизируется с конфигурацией кастомизации.
- Кнопки «Назад» удалены со внутренних страниц; оставлена только кнопка `⌂` возврата в меню.
- Gallery превращён в реальные достижения.
- Leaderboard теперь считает игрока по просмотрам + подписчикам, а не по деньгам.
- Добавлен `arcade.html` с 21 Card Challenge и Reaction Test без ставок.
- Старый lottery-режим заменён безопасной переадресацией в Arcade.
- RU / DE / EN добавлены/проверены для новых экранов и главного меню.
