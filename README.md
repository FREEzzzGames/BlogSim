# PLANET EARTH CONTROL DECK
Android kiosk dashboard and Ktor backend replacing BlogSim. Initial scaffold, not yet a verified production release.

Gradle modules: app, core design system/UI/network/database/datastore/domain/common, geophysics/weather/space/transport/infrastructure/settings/modal features, sync. Backend Ktor 3 with public feed adapters, PostgreSQL schema and Redis/Docker Compose scaffold. No fabricated measurements; keep secrets server-side.
